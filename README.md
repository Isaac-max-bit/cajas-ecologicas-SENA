
# 🌿 EcoBox - Calculadora de área superficial

Aplicación web desarrollada con JavaScript y Node.js
para calcular el área superficial de una caja de regalo
ecológica con forma de prisma rectangular.

## Descripción

EcoBox permite ingresar las dimensiones de una caja
(largo, ancho y alto) y calcular:

- Área superficial en cm² y m².
- Reserva adicional del 10 %.
- Cantidad total de material necesario.
- Validación de dimensiones positivas.

## Tecnologías utilizadas

- Node.js
- JavaScript
- HTML5
- CSS3
- Git y GitHub
- Fetch API

## Fórmula matemática

A = 2(l × w + l × h + w × h)

Reserva = A × 0.10

Material total = A + Reserva

## Instalación

1. Clonar el repositorio:

   git clone https://github.com/Isaac-max-bit/calculadora-caja-ecologica.git

2. Entrar en la carpeta:

   cd calculadora-caja-ecologica

3. Instalar Node.js si todavía no está instalado.

4. Ejecutar el proyecto:

   npm start

5. Abrir en el navegador:

   http://localhost:3000
